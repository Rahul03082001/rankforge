# Five-minute demo
1. **Search (1 minute):** Note collection size and run a dev example. Text is retrieved, not generated.
2. **Methods (1 minute):** Change Keyword → Semantic → Hybrid → Learned ranking. No method is guaranteed to win.
3. **Source (30 seconds):** Inspect document ID/full text and return.
4. **Compare (1 minute):** Same query across modes; explain differing score scales.
5. **Benchmark result (1 minute):** Show the saved development/test averages and split counts. Explain nDCG, MRR, and identical LTR/hybrid Recall@100. Current-query rankings are in Search explorer and Compare modes.
6. **Keyboard (30 seconds):** Type, Enter, radio keys, result open/back. Manual VoiceOver remains pending.

Before demo: verify readiness, all modes, correct full bundle/report, and public access if hosted. Localhost is not a public deployment.
